# 01 — API Types Design

> Package: `api/v1alpha1` · CRD: `PodASGMapping`

## Overview

The `api/v1alpha1` package defines the Kubernetes Custom Resource Definition (CRD) for `PodASGMapping`. This resource maps pod selectors to Azure Application Security Groups (ASGs), telling the controller which pod IPs to register in which ASGs.

## CRD Structure

```
PodASGMapping
├── metadata            (standard Kubernetes metadata)
├── spec
│   └── mappings[]      (one or more mapping rules)
│       ├── podSelector
│       │   └── matchLabels: map[string]string
│       └── applicationSecurityGroups[]
│           ├── resourceId:      full ARM resource ID
│           ├── subscriptionId:  optional override
│           └── description:     optional human label
└── status
    ├── conditions[]    (Accepted, Reconciled)
    ├── mappingCount    (len of spec.mappings)
    └── mappingStatuses[]
        ├── selectorHash   (deterministic hash)
        ├── matchedPods    (count)
        ├── asgSyncState   (Pending / Synced / Error)
        ├── lastSyncTime   (timestamp)
        └── error          (error message)
```

## Type Definitions

### `PodASGMapping` (CRD root)

```go
// +kubebuilder:object:root=true
// +kubebuilder:subresource:status
type PodASGMapping struct {
    metav1.TypeMeta   `json:",inline"`
    metav1.ObjectMeta `json:"metadata,omitempty"`
    Spec   PodASGMappingSpec   `json:"spec"`
    Status PodASGMappingStatus `json:"status,omitempty"`
}
```

Kubebuilder markers enable:
- `subresource:status` — status is updated independently from spec
- `printcolumn` — `kubectl get` shows `Mappings` count and `Age`

### `PodASGMappingSpec`

```go
type PodASGMappingSpec struct {
    // +kubebuilder:validation:MinItems=1
    Mappings []Mapping `json:"mappings"`
}
```

At least one mapping rule is required by CRD validation.

### `Mapping`

```go
type Mapping struct {
    PodSelector               PodSelector    `json:"podSelector"`
    // +kubebuilder:validation:MinItems=1
    ApplicationSecurityGroups []ASGReference `json:"applicationSecurityGroups"`
}
```

Each rule selects pods by labels and targets one or more ASGs.

### `ASGReference`

```go
type ASGReference struct {
    // +kubebuilder:validation:Pattern=`^/subscriptions/...`
    ResourceID     string `json:"resourceId"`
    SubscriptionID string `json:"subscriptionId,omitempty"`
    Description    string `json:"description,omitempty"`
}
```

The `ResourceID` has a CRD-level regex pattern validation. The controller performs additional structural parsing via `model.ParseASGResourceID()`.

### `PodASGMappingStatus`

```go
type PodASGMappingStatus struct {
    Conditions      []metav1.Condition `json:"conditions,omitempty"`
    MappingCount    int                `json:"mappingCount,omitempty"`
    MappingStatuses []MappingStatus    `json:"mappingStatuses,omitempty"`
}
```

### `MappingStatus`

```go
type MappingStatus struct {
    SelectorHash string      `json:"selectorHash"`
    MatchedPods  int         `json:"matchedPods"`
    ASGSyncState string      `json:"asgSyncState"`
    LastSyncTime metav1.Time `json:"lastSyncTime,omitempty"`
    Error        string      `json:"error,omitempty"`
}
```

The `SelectorHash` is a truncated SHA-256 of the sorted `matchLabels` key=value pairs. It enables correct `LastSyncTime` preservation when mapping rules are reordered in the spec.

## Conditions

Two conditions are maintained on each `PodASGMapping`:

| Condition | True | False | Unknown |
|-----------|------|-------|---------|
| `Accepted` | Spec is valid | Spec has validation errors | — |
| `Reconciled` | All ASGs synced | Action failures or reconcile error | Reconciling (pending) |

Conditions follow Kubernetes conventions:
- `ObservedGeneration` tracks which spec generation was processed
- `LastTransitionTime` is preserved when status/reason/message don't change
